> Smart To-Do List App :

This is a simple task management web application built by me using HTML, CSS, and JavaScript. It helps users manage daily tasks easily.

>> Features :
- Add new tasks
- Delete tasks
- Mark tasks as completed
- Press Enter key to quickly add tasks

>> Tech Used :
- HTML
- CSS
- JavaScript (DOM Manipulation)

>> How to Run :
Download the project and open index.html in any browser.

- How to use DOM manipulation
- Handling user events in JavaScript
- Creating dynamic UI elements
